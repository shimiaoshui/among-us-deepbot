Among Us DeepBot 0.10.0 + The Other Roles 4.6.0

Every human participant must install the matching host or client package from the same Release. The host configures 1-8 bots in the TOR lobby options and may customize each bot's name, color, outfit, and nameplate. Clients never create bots and do not need an API key.

Role counts, cooldowns, tasks, ability limits, and win resolution remain authoritative TOR/lobby rules. The modified TOR binary is distributed under GPLv3; the complete corresponding source and license are published with the Release.

No Among Us game files or API key are included.
